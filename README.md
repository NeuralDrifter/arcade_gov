# arcade_gov

This repository contains two collections of games derived from the official White House rcade.gov initiative.

## 1. wh-arcade/ (The Originals)
This folder contains the original arcade.gov games exactly as I reverse-engineered and rebuilt them from the source. They are preserved here in their original state for documentation and transparency.

## 2. nti-fascist games/ (The Alternatives - Work in Progress)
This folder contains our anti-fascist alternative mods. These are active works in progress where we are flipping the mechanics and themes of the propaganda games into protest games. 

*(For example: Rio Run has been modded so you are rounding up Team Trump for trial, and Noem actively chases a dog around the board).*

**Note:** The official White House footers and branding have been completely scrubbed from the standalone files in the anti-fascist folder to clearly distinguish them from the government versions.
